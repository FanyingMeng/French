# French · 法语背诵（扇贝式间隔重复）

纯前端小工具，三个模式：

| 模式 | 怎么练 | 数据 |
|---|---|---|
| 📖 普通单词 | 看中文 → 拼写法语 | `words.json` |
| 🔄 动词变位 | 看中文 → 拼写变位 | `verbs.json` |
| 💬 TCF 口语句子 | 看中文 → 先开口说 → Enter 看答案 → 自评（键盘 1 记住 / 2 没记住） | `sentences.json` |

## 复习规则（扇贝式）

- ⚙️ 设置里是**每日新词数**（默认单词 100、动词 50、句子 15）；**到期的复习全部出现**，
  所以每天总题数 = 新词 + 当天到期的复习，会随学习进度先增后减，但从不积压。
- 单词/动词的**新词第一次就拼对**：说明本来就会，直接约 7 天后再复习。
- 新词**答错**、订正后才过关：明天复习。句子是第一次学，记住了也从 1 天开始。
- 复习答对：间隔按 1 → 2 → 4 → 7 → 15 → 30 → 60 → 90 → 180 天往后推；
  7 天以上的会在 ±15% 范围内挑最空的一天，让每天的量更平均。
- 复习答错：当场订正，同一轮里再连续答对 2 次才算过关；间隔**降两级**，明天再见。
- 拼写判定会忽略弯/直撇号、多余空格和句末标点；只错重音时会单独提示。
- 词库学完后不会再清空重来，每天只剩到期复习。

## TCF 口语句子

`sentences.json` 一句一卡，按 [ouitcf.com](https://www.ouitcf.com/zh/practice/speaking) 的题目分类组织：

- **Task 2 通用句型**：开场、多种提问方式、追问、结束，所有题目都能用
- **Task 3 观点框架**：开头、论证、举例、让步、总结
- **Task 2 各小类**（31 个，比如"艺术、音乐、烹饪与兴趣课程"）：按每类题目里反复出现的提示词写的问句
- **Task 3 各子话题**：高频话题各有一两句可直接用的观点句

学习顺序 = id 顺序：先学通用句，再按该类在题库里的题数从多到少学。
每条格式：

```json
{"id": 1001, "task": 2, "cat": "大类", "topic": "小类", "cn": "中文提示", "fr": "法语句子"}
```

加新句子时 id 接着往后编即可。

## 发音

优先播放 `audio/` 里预生成的 mp3（加拿大法语神经语音 fr-CA-Sylvie），没有的才用词典音频或系统语音。

mp3 由 GitHub Actions 自动生成（`.github/workflows/tts.yml`），**免费、不需要任何账号**：
推送改动过的 JSON 后会自动补上新句子的音频。
换声音或某次生成失败时，可以在 GitHub 的 Actions 页面手动运行 "Generate audio"。

想换声音或在自己电脑上生成：

```bash
pip install edge-tts
python tools/gen_audio.py --voice fr-FR-DeniseNeural
```

## 进度备份 / 手机使用

- 进度存在浏览器里。⚙️ 设置 → **导出学习进度** 得到一个 json 文件，在另一台设备上 **导入** 即可。
- 用手机打开网页（GitHub Pages），iPhone 选 Safari 分享 → **添加到主屏幕**，就能像 App 一样全屏使用；听过的音频离线也能播放。
